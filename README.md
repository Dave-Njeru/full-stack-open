# Full Stack Open - University of Helsinki
This repository contains my solutions for the [Full Stack Open](https://fullstackopen.com/en/) course by the University of Helsinki. The course dives deep into modern web development using JavaScript, focusing on building single-page applications with React, Node.js, GraphQL, TypeScript and more.

## 📚 Course Outline
The course is divided into the following 14 parts:
- [x] Part 0: Fundamentals of Web apps
- [ ] Part 1: Introduction to React
- [ ] Part 2: Communicating with Server
- [ ] Part 3: Programming a server with NodeJS and Express
- [ ] Part 4: Testing Express servers, user administration
- [ ] Part 5: Testing React apps
- [ ] Part 6: Advanced state management
- [ ] Part 7: React router, custom hooks, styling app with CSS and webpack
- [ ] Part 8: GraphQL
- [ ] Part 9: TypeScript
- [ ] Part 10: React Native
- [ ] Part 11: CI/CD
- [ ] Part 12: Containers
- [ ] Part 13: Using relational databases

## 📦 Setup Instructions
1. Clone the repository
